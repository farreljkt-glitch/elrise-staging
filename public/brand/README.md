# Aset logo elrise
- `original/` — file asli dari pemilik merek (JPG, latar off-white).
- `icon-*.png`, `wordmark-*.png`, `lockup-*.png` — hasil ekstraksi transparan dari file asli; `-light` untuk latar terang, `-dark` untuk latar gelap (bagian navy dibuat terang agar terbaca).
- `icon-192/512.png`, `apple-touch-icon.png`, `favicon.png` — ikon aplikasi.
Warna merek: navy #123054, teal #31A28E. Komponen: components/brand/Logo.tsx.
